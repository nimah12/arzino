# ارزینو (Arzino) — قیمت لحظه‌ای ارز، طلا و سکه

پنل نمایش قیمت لحظه‌ای ارز، طلا و سکه به زبان فارسی/انگلیسی، با تم روشن/تیره، نمودار، جستجو و به‌روزرسانی خودکار. داده‌ی واقعی از وب‌سرویس [نوسان (Navasan)](https://navasan.tech) دریافت می‌شود.

---

## ✨ امکانات

- **قیمت زندهٔ ۱۰ دارایی**: دلار، یورو، پوند، درهم، لیر، طلای ۱۸ عیار، طلای آب‌شده (مثقال)، سکه امامی، نیم‌سکه و تتر (USDT).
- **دو زبانه (فارسی/انگلیسی)** با اعداد فارسی/لاتین و جهت RTL/LTR — انتخاب کاربر ذخیره می‌شود.
- **تم روشن/تیره** با ذخیرهٔ انتخاب و تشخیص خودکار تم سیستم (بدون پرش هنگام لود).
- **جدول واچ‌لیست**: قیمت، خرید/فروش (دلار)، تغییر ۲۴ ساعت، نمودار اسپارک‌لاین و زمان آخرین به‌روزرسانی هر دارایی.
- **نمودار بزرگ** با کلیک روی هر اسپارک‌لاین (مودال).
- **جستجوی زنده** میان دارایی‌ها.
- **فلش سبز/قرمز** قیمت هنگام تغییر بین رفرش‌ها.
- **کارت‌های خلاصهٔ بازار** (دلار، تتر، طلای ۱۸، سکه امامی).
- **پیام خطای واضح** وقتی کلید API نامعتبر است یا سرویس در دسترس نیست.
- **کانت‌داون تا رفرش بعدی** تا کاربر بداند داده فقط هر ۸ ساعت به‌روز می‌شود.
- **فونت وزیرمتن (Vazirmatn)** به‌صورت محلی (self-hosted) — بدون وابستگی به Google Fonts.
- **آیکون‌های Lucide** به‌جای SVG دستی.

## 🔑 منبع داده: وب‌سرویس نوسان (Navasan)

قیمت‌ها از `https://api.navasan.tech/latest/?api_key=...` خوانده می‌شوند.

- **کلید API**: به‌صورت پیش‌فرض در `src/lib/navasan.ts` است و از طریق متغیر محیطی `NAVASAN_API_KEY` قابل جای‌گذاری است.
- **پلن رایگان**: ۱۲۰ درخواست در ماه. برای همین برنامه حداکثر **۳ بار در روز** (هر ۸ ساعت) به API درخواست می‌دهد تا سهمیهٔ ماهانه (۹۰ درخواست) نسوزد.
- **واحدها**: ارزها و طلای ۱۸ عیار به **تومان** و سکه‌ها و مثقال طلای آب‌شده به **هزار تومان** گزارش می‌شوند؛ در `PRICE_SCALE` (`src/lib/navasan.ts`) ضریب ×۱۰۰۰ برای این نمادها اعمال شده است.

### نگاشت نمادها

| دارایی | نماد Navasan | واحد |

| دلار آمریکا | `usd_sell` / `usd_buy` | تومان |

| نیم‌سکه | `nim` | هزار تومان (×۱۰۰۰) |
| تتر (USDT) | `usdt` | تومان |

## ⏱ معماری کش و محدودیت ۳ بار در روز

به‌دلیل سهمیهٔ رایگان نوسان (۱۲۰ درخواست/ماه)، داده‌ها به‌صورت محافظه‌کارانه کش می‌شوند:

1. **بازهٔ ۸ ساعته** (`REFRESH_MS` در `src/lib/prices-server.ts`): بعد از هر تلاش موفق یا ناموفق، تا ۸ ساعت به API درخواست جدیدی ارسال نمی‌شود.
2. **ذخیره روی دیسک**: کش و وضعیت (داده، زمان کش، زمان آخرین تلاش، زمان آپدیت نوسان، وضعیت خطا) در `var/arzino-cache.json` ذخیره می‌شود. با ری‌استارت سرور، اگر هنوز ۸ ساعت نگذشته باشد، API اصلاً صدا زده نمی‌شود. این فایل در `.gitignore` است.
3. **خطا هم محدود است**: اگر کلید نامعتبر باشد یا درخواست خطا بدهد، تلاش مجدد هم فقط هر ۸ ساعت انجام می‌شود (تا کلید به‌خاطر ریکوئست‌های تکراری مسدود نشود).
4. **سرویس‌دهی به کلاینت**: UI هر ۱ دقیقه از سرور خودمان (`/api/prices`) می‌گیرد؛ سهمیهٔ نوسان هیچ‌وقت با رفرش صفحه‌ها مصرف نمی‌شود. کانت‌داون «بروزرسانی بعدی» دقیقاً همین بازه را نشان می‌دهد و رفرش زودهنگام فقط یک پیام آموزشی نشان می‌دهد.

### رفتار خطا

- کلید نامعتبر → بنر قرمز: «کلید API نامعتبر است … (تلاش مجدد هر ۸ ساعت)».
- قطعی سرویس/خطای شبکه → بنر قرمز: «دریافت قیمت‌های زنده ناموفق بود …».
- در همهٔ حالت‌های خطا، جدول با fallback (خط تیره) پر می‌شود تا چیدمان حفظ شود.
- بعد از موفقیت، خطا پاک و قیمت‌های واقعی جایگزین می‌شوند.

## 📊 دربارهٔ نمودارها

نمودارها (اسپارک‌لاین و مودال بزرگ) **نمایشی و مصنوعی** هستند — سرویس نوسان تاریخچهٔ قیمت ارائه نمی‌دهد. هر نمودار یک منحنی صاف و قطعی (deterministic) حول قیمت فعلی دارایی می‌سازد که:

- در بازهٔ منطقی ±۱–۲٪ قیمت باقی می‌ماند (هیچ دارایی روی کف قفل یا چند ده درصد منحرف نمی‌شود).
- جهت کلی آن با «تغییر ۲۴ ساعت» واقعی هم‌راستاست (▲ صعودی / ▼ نزولی).
- انیمیشن رسم خط هر ۱ دقیقه (با تیک ساعت) تکرار می‌شود تا حس «زنده» بودن حفظ شود.

برای داشتن نمودار بر پایهٔ دادهٔ واقعی، سرویسی با تاریخچهٔ قیمت لازم است (مثلاً پلن پولی نوسان).

## 📝 نکات توسعه

- **ماژول‌های سرور/کلاینت جدا هستند**: `prices-server.ts` از `fs` استفاده می‌کند و هرگز وارد باندل کلاینت نمی‌شود؛ `prices.ts` فقط تایپ و تابع‌های نمایشی دارد.
- اگر کش را دستی تست می‌کنید: `rm -f var/arzino-cache.json` و سرور را ری‌استارت کنید تا یک درخواست واقعی به نوسان برود.
- نسخهٔ کش (`CACHE_VERSION`) با تغییر ساختار داده تغییر می‌کند تا کش‌های قدیمی نادیده گرفته شوند.
